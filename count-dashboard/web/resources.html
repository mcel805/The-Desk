USING THE CHAT

Get a grounded chart read

  1. Choose the asset and timeframe on Count Desk.
  2. Build the count so the current chart snapshot is ready.
  3. Ask a question such as “What is the 30-minute structure, and what would invalidate that read?”
  4. Check Batty’s answer for the data source, last-bar time, and provisional labels.
CURRENT INTEGRATION

What Batty can read today

  • Count Desk: selected asset/interval, up to 64 latest bars, structural count layers, saved drawings, key analytics, and feed status.
  • Trading Journal: active tab and visible filters. Private account ledger rows are not sent with the prompt.
  • Resources: this guide and the current integration notes.
  • Model: local Codex CLI, authenticated with your ChatGPT sign-in and the model/effort selected below the composer.
FIRSTMATE · COORDINATION LAYER

How the crew model is intended to work

Firstmate is the coordinator and agent operating system, not a language model. Batty is the human-facing first mate: it decides whether a specialist would help, delegates through Firstmate, checks the returned evidence, and gives you one answer.

The current local Firstmate installation does not have a supported browser-chat bridge for creating, continuing, reading, and stopping a crew task. The crew seats shown in the dashboard are role definitions and status UI; they do not mean a specialist ran. Batty will say when it worked alone.

DATA & CONTROL

Clear limits, useful answers

  • Stored bars may be delayed or stale; a chart snapshot is not a live quote.
  • Structural count labels and projected paths are research aids, not validated Elliott counts.
  • The chat currently cannot search the web, take over another app, or change dashboard settings.
  • It cannot route orders. Research replies are not trade instructions.
  • Model use follows the signed-in ChatGPT plan and its limits; it is not an OpenAI API-key connection.
