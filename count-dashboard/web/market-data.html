REFERENCE FLOW

TradingView broker verification

Broker integration

TradingView can verify certain brokers' exchange subscriptions because it has a broker connection and agreements for that flow.

  1. Sign in to TradingView and connect AMP from its Trading Panel.
  2. TradingView checks eligible subscriptions on the connected account.
  3. The verified entitlement applies inside TradingView for supported exchanges.

That verification does not pass the feed or a reusable data license to Vela. Count Desk needs its own approved source connection. Do not enter TradingView or AMP passwords on this page.

IF THIS BECOMES A MULTI-USER PLATFORM

Customer data access is a different agreement

If Count Desk serves other traders, each customer's AMP login cannot simply be reused as a platform-wide data plan. The company would need a CQG/vendor agreement that covers customer-facing API use, exchange permissions, user counts, display, non-display analysis, derived data, storage, and redistribution. CQG describes WebAPI as an enterprise API; get written scope and pricing before designing a hosted relay.
