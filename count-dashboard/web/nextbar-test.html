Method, eligibility, and saved evidence

Jev selects two prices from a fixed −4 to +4 ATR grid, including an unavailable option. These are experimental point forecasts of the next high and low, rounded outward to your analysis tick unit. This grid is bounded and is not an exact continuous-price regression model. Confidence describes a typed selection, not trading success.

The next bar is withheld from every model request. Replay results are historical or synthetic demonstrations; they do not establish a live edge. Forward reads must start within 15 seconds of bar open and return before that candle closes. Responses taking 30 seconds or more are flagged; slow and late rows stay in receipts and are excluded from the paired comparison.

Table rates use all resolved baseline candles and all valid resolved Jev candles. The paired comparison uses only the same timely valid candles for both methods. Failures and abstentions remain visible in coverage. A rough screen needs at least 100 paired real-data candles; a favorable screen still needs held-out validation. CSV times must be UTC-aligned, complete, and contiguous; the analysis tick is a user setting, not an exchange specification.

Reset starts a new run; old server receipts remain preserved. Download receipts before changing charts. A paused live forecast can still be resolved with Step. Closing this page stops new requests; there is no unattended worker.
