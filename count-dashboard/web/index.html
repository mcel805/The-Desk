PREMIUM INDICATOR / v1.0.0

Liquidity · User guide

What it maps

  • External BSL: a confirmed swing high. The zone spans the wick high to the pivot candle body high.
  • External SSL: a confirmed swing low. The zone spans the pivot candle body low to the wick low.
  • Internal BSL / SSL: confirmed smaller swing highs/lows strictly inside the latest confirmed external high/low range. Internal levels are single prices.
  • Lifecycle: a level begins NEW, becomes TOUCHED on overlap, and becomes BROKEN after a later bar closes through its outer edge. Broken lines stop at that close.

Defaults and confirmation

  • External pivot length: 14 bars to the left and right. Internal pivot length: 5 bars each side. Both can be changed in the Tool Belt map.
  • A pivot is not available until its right-side confirmation bars have closed. The line is drawn back to its pivot candle for context; its recorded confirmedTime is when it first became knowable.
  • The latest stored candle is excluded because the app cannot prove that bar has closed. The displayed cutoff and input hash identify the calculation snapshot.
  • Times in the ledger are displayed in your browser’s local timezone; source retrieval metadata retains its source timestamp.

Identifier and evidence

  • Each tag such as LQ-EXT-BSL-A1B2C3D4 shows a short ID derived from a repeatable 16-character identifier tied to engine version, symbol, timeframe, pivot side/type, and pivot time. The full ID is in the workbench ledger with price range, pivot/confirmation/break times, and touch count.
  • Active levels use a restrained teal/red pencil line. Internal lines are dotted. Broken levels turn grey and dashed. “Replay last stored break” plays a small impact ripple on the most recent historical break; it is not a live alert.
  • Probability, directional bias, order-book liquidity, and trading performance are not measured here. The Tool Belt’s 50/50 coin is a display placeholder only. This version does not learn or alter its own rules.

Source: user-provided TradingView Pine v5 script and MYM1! chart image, dated 2026-09-29. This app version ports only the script’s confirmed external swing and internal pivot level logic; it omits equal highs/lows, previous day/week, MTF, spikes, bias, structure panels, premium/discount, probabilities, targets, and alerts. Stored bar provenance is shown with each workbench run; feed rights are not established by this tool.

PREMIUM INDICATOR / v1.0.0

Bias · User guide

Bias v1 reads confirmed market structure first. Prior-day and prior-week liquidity sweeps remain a separate context read based on the existing Batty Pine rules.

Primary structure read

  • Default pivot length is 5 bars on each side. A high or low becomes usable only after its right-side confirmation bars close. The pivot is anchored at its origin time, with its later confirmation time retained in the result.
  • Bullish sequence: the latest two confirmed swing highs and lows both rise (HH + HL). Bearish sequence: both fall (LH + LL). All other combinations read MIXED.
  • BOS: a later bar closes across a previously confirmed swing high or low, beyond the configured acceptance buffer. CHoCH: the close-through opposes the prior confirmed structure direction or the previous active break direction.
  • A break against the currently confirmed swing sequence displays a transition as MIXED until the swing sequence confirms. The tool does not project an unconfirmed swing or label a wick-only breach as a structure break.
  • When stored data exists, the latest fully closed daily structure is shown as higher-timeframe context for intraday charts; the latest weekly structure is shown for daily charts. Alignment is reported as aligned, conflict, mixed, or unavailable. Directional conflict displays an overall MIXED tag while preserving both timeframe reads.

Prior-period context carried forward

  • The original script’s PDL/PWL sweep-and-reclaim and PDH/PWH sweep-and-reject rules, plus close acceptance beyond prior highs/lows, are kept as a separate daily-reset context state.
  • That legacy context does not override the market-structure read. If it disagrees, the workbench marks the conflict for review instead of silently flipping directional bias.
  • Tick buffers use MYM 0.25, MCL 0.01, and MGC 0.10. An unrecognized symbol is shown with unknown tick size and uses a zero buffer until its specification is added.

Data, timing, and limits

  • The latest stored chart bar is excluded; the cutoff, settings, source datasets, and snapshot hash are displayed for each run. Daily and weekly context uses only the period before the one containing the chart bar.
  • Confirmed pivots are non-repainting by construction, but confirmation is delayed by the right-side pivot length. A historical pivot mark is drawn at its origin only after it became knowable.
  • Bias is a descriptive market-structure state. The probability display remains a coin-flip placeholder and there is no measured hit rate, expectancy, automatic learning, target, or trade instruction.

Source: existing Bias / Draw Panel logic in the user-provided TradingView Pine v5 script and the Count Desk’s confirmed swing conventions. This build omits the script’s DRAW target selection, premium/discount choices, sweep-counting, ATR line, alerts, and measured zone-probability system. A close-through definition and HH/HL structure sequence are explicit v1 rules, not a claim of validated predictive edge.
