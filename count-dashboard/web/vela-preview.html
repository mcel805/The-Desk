AGENT CONTEXT · MCP

MCP reference

Separate from chart feeds

MCP tools can provide research or account context. A listed server does not imply an active session, chart feed, data license, or order permission in Count Desk.

TradingView MCPExternal reference · not wired

Delayed quotes and price history, screeners, fundamentals, news, watchlists, and alerts in TradingView’s public beta. It is not the Count Desk chart or count feed.

Official source ↗
Robinhood Trading MCPBroker research pilot · planned

Account, portfolio, transaction, and market tools. Robinhood also exposes order tools; Count Desk’s proposed use is a separate read-only research import.

Official source ↗
LuxAlgo MCP · local sidecarConditional · check Resources

Vendored library, broker-read, Edge Stats, and public-record research tools. The local Cleo sidecar starts only when enabled; its journal writes and execution tools are excluded.

Upstream source ↗Local capability report →
Edge Stats MCPVendored · local research

Read-only queries over a local, authorized historical store with sample sizes and uncertainty. The standalone MCP package is present in source; no active server is implied.
