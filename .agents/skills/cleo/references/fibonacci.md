# Fibonacci retracements and extensions

- State the swing anchors, direction, chart scale, ratio, formula, timeframe and source. For a rise from low L to high H, a retracement r is `H - r*(H-L)`; reverse consistently for a decline. Verify arithmetic and round to tick size only when known.
- Choose anchors using a declared pivot rule before inspecting the outcome. If multiple plausible swings exist, show the alternatives or mark the level ambiguous. Never move anchors retrospectively to make a level fit.
- Use a small relevant set of ratios and label a zone as a measured reference, not a forecast certainty. Confluence with liquidity, structure or support/resistance is still not independent evidence unless tested as such.
- Distinguish retracement (inside the measured swing) from extension/projection (outside it). State which leg is projected and the conditional scenario required.
- Keep log/linear settings explicit; TradingView supports an alternative calculation on logarithmic charts. Do not infer setting from a screenshot.
