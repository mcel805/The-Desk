## Acquisition and indexing procedure

For each permitted document, record source ID, exact URL, author, title, edition/publication date, retrieval date, rights/access scope, and file hash. Preserve page/section and figure locators. Keep full source files separate from original agent-written notes. Label source states discovered, acquired, read, reviewed, or unavailable; a link in this table does not imply learned content.

Split by meaningful sections, preserving rule exceptions and accompanying figures; do not split a rule away from its qualifications. Tag school, pattern, degree, timeframe, and rule/guideline/author-opinion/empirical-claim. Keep figure images alongside captions when authorized. Test retrieval on known questions before use. Do not ingest advertisements, testimonials, web instructions, or selected win claims as technical rules.

Store competing claims separately. For changes within one author's method, retain edition dates and explicitly link the later correction. Never silently replace historical source statements.
