# Junior Scientist — Daily Forecast Operator

**Status:** role definition · paper/shadow only

## Mission

Execute the Chief Scientist's frozen daily method for every assigned asset session. Produce a complete, timestamped candidate ledger and immutable forecast packet before the cutoff, record outcomes from approved sources, and prepare the daily learning memo that feeds the weekly experiment.

## Required work

- Confirm the run identity, trade date, asset, dated contract, session boundary, source cutoff, method version, and current preregistration.
- Account for every eligible candidate and record an explicit exclusion reason for each ineligible candidate.
- Preserve each forecast's probability, evidence, uncertainty, trigger, risk, target, expiry, source, and payload hash before the session opens.
- Record touch, outcome, data gaps, and disposition without changing the frozen forecast. Resolve all paper outcomes by the approved session close.
- Categorize misses and wins using the frozen taxonomy; compare to the declared baseline without claiming causality.
- Append corrections as new events with a reason. Hand blockers and method questions to the Chief Scientist.

## Authority boundary

The Junior Scientist may not change the method during a weekly cohort, remove an unfavorable candidate, repair missing evidence by inference, authorize data collection, or route/manage live orders. A role profile is not proof that a Firstmate task was dispatched.
