Connect futures data to The Desk

You can test synthetic candles, quotes, timeframe changes and disconnect recovery without an IBKR account. The demo never contacts IBKR and never enables futures orders.

Try the account-free demo

From apps/the-desk, start an isolated server:

python3 server.py --port 18882 --data-dir /tmp/desk-ibkr-demo --no-workers --ibkr-mode demo

Open http://127.0.0.1:18882/. The synthetic MYM December 2026 fixture is marked DEMO DATA. It invents weekend activity too. Use IBKR data → Pause demo feed / Resume demo feed to inspect a disconnected chart. No crypto feed or journal worker starts with --no-workers.

Later: an authenticated Gateway connection

  1. Use an eligible funded IBKR account with the appropriate CBOT/API data entitlement and acknowledgements. MYM needs CBOT coverage. Verify your signed terms, display use and retention scope; automated/non-display and external AI access require separate review.
  2. Install the official TWS API Python package from IBKR's distribution using a compatible Python runtime. The current API documents Python 3.11+. No unofficial pip package is installed by The Desk.
  3. Log into TWS or IB Gateway yourself. Keep Read-Only API enabled. For TWS enable socket clients. Confirm the configured port, unique client ID and loopback access. This adapter performs no account or order requests.
  4. Set the exact contract month and confirmed local display access, then start Gateway mode. The port below is the usual paper Gateway default; verify your actual settings.
export DESK_IBKR_CONTRACT_MONTH=202612
export DESK_IBKR_HOST=127.0.0.1
export DESK_IBKR_PORT=4002
export DESK_IBKR_CLIENT_ID=47
# Set these only after confirming your actual entitlement and permitted use:
export DESK_IBKR_MARKET_DATA_CONFIRMED=1
export DESK_IBKR_LOCAL_DISPLAY_CONFIRMED=1
python3 server.py --port 18882 --data-dir /tmp/desk-ibkr-gateway --ibkr-mode gateway

December 2026 is an example expiry, not an automatic front-month selection. The API must resolve exactly one MYM FUT contract. Inspect its returned conId, expiry, exchange, tick and multiplier in the IBKR panel before using the chart.

First-release scope

Recent, bounded 600-bar intraday TRADES history: 1m, 3m, 5m, 15m, 30m, 1h and 4h. Historical bars preserve the broker's timestamps and session boundaries. There is no continuous-contract stitching, automatic rollover, daily-bar conversion, full archive, exchange holiday calendar, depth, tick tape or futures trading. Browser updates poll the local adapter once per second; the adapter maintains IBKR subscriptions. Quote labels preserve unknown, delayed and frozen modes. A quiet market may show stale data; no exchange-closed state is inferred.

Gateway starts only with --ibkr-mode gateway; the default is off. Demo and real configurations use separate databases/ports. Data is held in memory, outside the paper engine and journal. Saved chart layouts can still contain symbol and drawing metadata. No account-free test establishes authentication, real CME entitlements, real data accuracy, wire-protocol compatibility, broker fills or measured latency.
