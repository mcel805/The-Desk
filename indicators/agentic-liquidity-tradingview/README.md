# Agentic - Liquidity — TradingView edition

Paste `Agentic_Liquidity_TradingView.pine` into a new TradingView Pine Editor indicator, save, and add to chart. Start with standard 1-hour candles, matching the supplied ETH screenshot. Default manual sources are 60, 30 and 15 minutes. Automatic higher-chart context additionally enables the 4H source on 4H and higher charts, and Daily on Daily and higher charts. Disable **Include 4H / Daily context on higher charts** for manual-only selection. Use the same provider, symbol, history and settings for a meaningful numerical comparison.

The default Clean presentation shows exact red high-pool and green low-pool lines with timeframe and descriptive strength badges, such as `60+30+15 · 80/100`. Values are calculated from the supplied convergence and price-buildup logic; screenshot scores are not hardcoded. This is a chart-evidence score, not a reversal probability or measured order quantity. Source pivot origins are drawn retrospectively after confirmation.

Red high pools are **BSL (buy-side liquidity)**; green low pools are **SSL (sell-side liquidity)**. The previous global nearest-level cap could let one crowded side hide the other, and multi-source-first badge ranking could omit a lone single-source level. Clean selection now alternates the nearest pockets on each side and reserves a line for every selected pocket. If only one side has active confirmed pools, its unused slots are reused; no consumed or invented level is substituted.

Badges start to the right of the active candle. Main lines and optional shading stop before that tag column. Opaque badge backgrounds default on. Neighboring tags merge into one badge using a configurable fraction of the visible candle price range; their original individual price lines stay exact. A merged badge unions the source frames and shows a min–max strength range and pocket count, for example `60+30+15 · 18-90/100 ×3`. Merging never adds scores. A nearby opposing-side collision can share one neutral badge with two frame/score sections. SSL/BSL prefixes are omitted from visible badges; line colors identify the side. **Forward display bars** moves the column; **Gap before tag column** sets the line-to-tag gap; **Merge crowded tags** adjusts collision spacing for pane height and vertical zoom. Pine does not expose screen pixel text bounds, so increase this spacing if the chart pane is very short. Leave right-side chart margin for the tags.

Clean line width/transparency and badge text size/transparency are configurable in **05 · Clean display**. Main shading is off by default, standalone chart-swing strips default to zero, and optional white 1-minute structure guides default off. Source small-pool evidence still contributes to the score when its strips are hidden. Enable **Shade clean pockets / bands** to restore shared shading, or choose **Original** presentation for the supplied strip/band display. Supplemental yellow 5-minute pockets remain enabled only on 1–5-minute charts, as in the source.

The 4H screenshot exposed source coverage limits beyond the earlier display fix: 4H was disabled by default; highs and lows shared a retention capacity; and 400 source bars were requested even though pool age defaulted to 1,000 bars. The updated source automatically includes higher-chart context, requests at least the configured pool age plus two pivot windows of warm-up, and keeps separate capacities on each side. Capacity cleanup removes consumed pools first, then internal pools before external anchors. Capacity remains finite, and source age/consumption rules still apply. No synthetic or already-consumed level is substituted.

Source pivot definitions, nested minute consumption, bridge schema, chart-swing evidence, strength formulas, structure conditions and yellow reference pockets are retained. Broader source coverage can intentionally change available bridge prices and convergence scores. The Original-view appearance controls remain available. Two small native alert fixes are included: the four alert message plots now occupy the first four plot slots, and **All enabled** alert scope includes every enabled source independently of the bridge scope. TradingView documents alert plot placeholders in its [Pine alerts reference](https://www.tradingview.com/pine-script-docs/concepts/alerts/#placeholders).

The screenshot's Sell/Buy buttons and working order, stop-loss and take-profit widgets are platform trading controls. They are outside this liquidity source and are not recreated by this indicator. The script does not send orders or add a separate ABC/Elliott engine. To use the supplied structure warnings, create a TradingView alert from either of the two named conditions; prefer Once Per Bar Close for chart-close confirmation. Turning off structure drawings does not disable the alert conditions.

`source-original.pine` preserves the attachment byte for byte. Original MPL 2.0 and author notices remain in the adapted script.

Local validation: `node verify.mjs` from this directory. Synthetic tests cover automatic 4H and Daily selection, manual opt-out, requested source warm-up, separate high/low capacities and external-anchor survival under opposite-side/internal pivot churn. Prior display tests cover rightward tag geometry and deterministic Pine display packets with crowded lows, crowded highs, an empty opposite side, and adjacent opposing tags; 1m nested/reference and Original-view execution remain checked. See `validation.json`.

The local PineTS host incorrectly reports a requested context's timeframe for `timeframe.main_period`; the verifier substitutes the known chart timeframe into its test copy to match the [documented native invariant](https://www.tradingview.com/pine-script-docs/concepts/chart-information/#chart-timeframe). The delivered Pine uses the native built-in unchanged. Local compatibility checks do not establish native TradingView compilation, live alert delivery, or matching-OHLC screenshot parity. Compile and test the final script in TradingView.

The latest formatting edit removes the visible SSL/BSL tag prefixes. The full focused regression suite was rerun against this final archived version, including the shorter tag captions.
